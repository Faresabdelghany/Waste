# WasteHero Business Module Map

This document assigns the current UI to the canonical business modules in
`PRODUCT_BUSINESS_BLUEPRINT.md`. It is an ownership and dependency map, not a
copy of the current navigation.

The machine-readable companion is
[`lib/data/business-domain.ts`](../lib/data/business-domain.ts). That registry
maps every current public workspace tab to a primary blueprint module,
supporting modules, personas, upstream dependencies, downstream consumers, and
important boundary notes.

## Priority legend

- **P0 — foundation or safety:** required to preserve tenant scope, canonical
  identity, financial integrity, or a restricted persona boundary.
- **P1 — core workflow:** needed for the module to do its main business job.
- **P2 — optional/evolving:** valuable after its upstream records and controls
  are trustworthy.

## Canonical relationship spine

The first connected implementation should support this path with stable IDs and
clickable routes:

```text
Company → Project → Customer/Property → Agreement/Subscription
→ Product/Price → Collection Calendar/Route Scheme
→ planned Vehicle Allocation → daily Route → actual Assignment/Route Session
→ Stop Outcome/Proof/Weight → Alert/Ticket/Conversation
→ Billable Event → Billing Run → Invoice → Credit Note
```

Supporting branches:

```text
Asset ↔ Property/Shared Point ↔ Warehouse/Stock Movement
Contractor → Contract Area → Route Scheme responsibility → Route
Contractor Proposal → Approval → new effective Route Scheme version
Route Studio Scenario → immutable Plan → Approval → Promotion
Autopilot Flow Version → Simulation → Approval → Action → Run → Impact
Integration → Credential → Mapping → Job → Result/Error → Domain record
Record → Document/Evidence → Version/Approval → Audit Event → Retention
Lead → Offer → Subscription → Entitlement → Company/Project feature
Order → Payment → Inventory Reservation → Invoice → Fulfillment
```

Every relationship should carry the related entity type, stable ID, label,
company/project scope, and permission-aware URL. A display string with an arrow
icon is not a business relationship.
