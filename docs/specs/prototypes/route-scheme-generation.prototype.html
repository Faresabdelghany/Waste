Route Scheme generation model

The question this answers: when a Route Scheme (a recurring template — e.g. “every Sunday, these 12 glass containers, truck WH-31, driver Freja”) generates dated Routes, does the model behave sensibly? Specifically: regenerating must never duplicate; editing the scheme must only touch routes that haven’t left Planned; holiday deviations must move dates; a hand-picked driver on one route must survive regeneration; and started or finished routes must be untouchable. Press the buttons and see if anything feels wrong. Simulated today: Fri 28 Aug 2026.
